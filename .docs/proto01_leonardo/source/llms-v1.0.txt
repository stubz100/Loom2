## API Reference: Rest Endpoints
- [List Blueprints](https://docs.leonardo.ai/v1.0/reference/listblueprints.md): Returns a list of Blueprints. Use either forward pagination (first/after) or backward pagination (last/before), but not both. Note: This endpoint uses a request body to support complex filtering…
- [Get Blueprint by ID](https://docs.leonardo.ai/v1.0/reference/getblueprintbyid.md): Returns a single Blueprint by its akUUID
- [Get Blueprint Versions by Blueprint ID](https://docs.leonardo.ai/v1.0/reference/getblueprintversionsbyblueprintid.md): Returns all versions of a Blueprint by its akUUID
- [Execute a Blueprint](https://docs.leonardo.ai/v1.0/reference/executeblueprint.md): Execute a Blueprint Version with custom node inputs. This endpoint triggers the execution of the specified Blueprint Version and returns a Blueprint Execution ID to track the job.
- [Get Blueprint Execution by ID](https://docs.leonardo.ai/v1.0/reference/getblueprintexecution.md): Retrieves details of a specific Blueprint Execution by its akUUID
- [Get Blueprint Execution Generations by Execution ID](https://docs.leonardo.ai/v1.0/reference/getblueprintexecutiongenerations.md): Retrieves paginated generations for a specific Blueprint Execution, including their statuses and any prompt moderation failure details.
- [Create a Dataset](https://docs.leonardo.ai/v1.0/reference/createdataset.md): This endpoint creates a new dataset
- [Get a Single Dataset by ID](https://docs.leonardo.ai/v1.0/reference/getdatasetbyid.md): This endpoint gets the specific dataset
- [Delete a Single Dataset by ID](https://docs.leonardo.ai/v1.0/reference/deletedatasetbyid.md): This endpoint deletes the specific dataset
- [Upload dataset image](https://docs.leonardo.ai/v1.0/reference/uploaddatasetimage.md): This endpoint returns presigned details to upload a dataset image to S3
- [Upload a Single Generated Image to a Dataset](https://docs.leonardo.ai/v1.0/reference/uploaddatasetimagefromgen.md): This endpoint will upload a previously generated image to the dataset
- [Get a Single Custom Element by ID](https://docs.leonardo.ai/v1.0/reference/getelementbyid.md): This endpoint gets the specific custom element.
- [Delete a Single Custom Element by ID](https://docs.leonardo.ai/v1.0/reference/deleteelementbyid.md): This endpoint will delete a specific custom model.
- [Get a list of Custom Elements by User ID](https://docs.leonardo.ai/v1.0/reference/getcustomelementsbyuserid.md): This endpoint gets the list of custom elements belongs to the user.
- [Train a Custom Element](https://docs.leonardo.ai/v1.0/reference/createelement.md): This endpoint will train a new custom element.
- [List Elements](https://docs.leonardo.ai/v1.0/reference/listelements.md): Get a list of public Elements available for use with generations.
- [Create a Generation of Images](https://docs.leonardo.ai/v1.0/reference/creategeneration.md): This endpoint will generate images
- [Get a Single Generation](https://docs.leonardo.ai/v1.0/reference/getgenerationbyid.md): This endpoint will provide information about a specific generation
- [Delete a Single Generation](https://docs.leonardo.ai/v1.0/reference/deletegenerationbyid.md): This endpoint deletes a specific generation
- [Get generations by user ID](https://docs.leonardo.ai/v1.0/reference/getgenerationsbyuserid.md): This endpoint returns all generations by a specific user
- [Upload init image](https://docs.leonardo.ai/v1.0/reference/uploadinitimage.md): This endpoint returns presigned details to upload an init image to S3
- [Get single init image](https://docs.leonardo.ai/v1.0/reference/getinitimagebyid.md): This endpoint will return a single init image
- [Delete init image](https://docs.leonardo.ai/v1.0/reference/deleteinitimagebyid.md): This endpoint deletes an init image
- [Upload Canvas Editor init and mask image](https://docs.leonardo.ai/v1.0/reference/uploadcanvasinitimage.md): This endpoint returns presigned details to upload an init image and a mask image to S3
- [Upload media](https://docs.leonardo.ai/v1.0/reference/uploadmedia.md): This endpoint returns presigned POST credentials to upload a video or audio file directly to S3.
- [Get uploaded media](https://docs.leonardo.ai/v1.0/reference/getuploadedmediabyid.md): This endpoint returns details of an uploaded media record
- [Delete uploaded media](https://docs.leonardo.ai/v1.0/reference/deleteuploadedmediabyid.md): This endpoint deletes an uploaded media record and removes the associated file from S3
- [Create a video generation from an image](https://docs.leonardo.ai/v1.0/reference/createimagetovideogeneration.md): This endpoint will generate a video using an uploaded or generated image.
- [Create a video generation from a text prompt](https://docs.leonardo.ai/v1.0/reference/createtexttovideogeneration.md): This endpoint will generate a video using a text prompt
- [Train a Custom Model](https://docs.leonardo.ai/v1.0/reference/createmodel.md): This endpoint will train a new custom model
- [Get a Single Custom Model by ID](https://docs.leonardo.ai/v1.0/reference/getmodelbyid.md): This endpoint gets the specific custom model
- [Delete a Single Custom Model by ID](https://docs.leonardo.ai/v1.0/reference/deletemodelbyid.md): This endpoint will delete a specific custom model
- [Get a list of Custom Models by User ID](https://docs.leonardo.ai/v1.0/reference/getcustommodelsbyuserid.md): This endpoint gets the list of custom models belongs to the user.
- [List Platform Models](https://docs.leonardo.ai/v1.0/reference/listplatformmodels.md): Get a list of public Platform Models available for use with generations.
- [Generate a Random prompt](https://docs.leonardo.ai/v1.0/reference/promptrandom.md): This endpoint returns a random prompt
- [Improve a Prompt](https://docs.leonardo.ai/v1.0/reference/promptimprove.md): This endpoint returns a improved prompt
- [Create LCM Generation](https://docs.leonardo.ai/v1.0/reference/createlcmgeneration.md): This endpoint will generate a LCM image generation.
- [Perform instant refine on a LCM image](https://docs.leonardo.ai/v1.0/reference/performinstantrefine.md): This endpoint will perform instant refine on a LCM image
- [Perform Alchemy Upscale on a LCM image](https://docs.leonardo.ai/v1.0/reference/performalchemyupscalelcm.md): This endpoint will perform Alchemy Upscale on a LCM image
- [Create unzoom](https://docs.leonardo.ai/v1.0/reference/createvariationunzoom.md): This endpoint will create an unzoom variation for the provided image ID
- [Create upscale](https://docs.leonardo.ai/v1.0/reference/createvariationupscale.md): This endpoint will create an upscale for the provided image ID
- [Create no background](https://docs.leonardo.ai/v1.0/reference/createvariationnobg.md): This endpoint will create a no background variation of the provided image ID
- [Create using Universal Upscaler](https://docs.leonardo.ai/v1.0/reference/createuniversalupscalerjob.md): This endpoint will create a high resolution image using Universal Upscaler
- [Get variation by ID](https://docs.leonardo.ai/v1.0/reference/getvariationbyid.md): This endpoint will get the variation by ID
- [Get motion variation by ID](https://docs.leonardo.ai/v1.0/reference/getmotionvariationbyid.md): This endpoint will get the motion variation by ID
